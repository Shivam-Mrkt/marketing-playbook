# Conversion experiments

The useful outcome is an informed action from a suitable visitor. Reducing friction can improve submission volume while weakening lead quality.

## Illustrative example: B2B SaaS

This completed example uses fictional RelayDesk data; it is not a personal achievement or a conclusive statistical result.

| Stage | Record |
| --- | --- |
| Problem | The demo form may ask for more effort than visitors expect |
| Hypothesis | Removing the use-case question will increase qualified leads per visitor |
| Change | Remove that one question; keep page, traffic and follow-up comparable |
| Metric | Qualified leads per eligible visitor; raw submissions, sales effort and contactability are diagnostics |
| Test | Four-week stable visitor split, then 14 days for qualification; directional pilot |
| Result | Control: 1,000 visitors, 50 leads, 20 qualified. Treatment: 1,000 visitors, 70 leads, 14 qualified |
| Learning | Submission rate rose from 5% to 7%, but qualified conversion fell from 2% to 1.4%. The observed trade-off does not support the hypothesis |
| Next action | Retain the original form for now; inspect rejection reasons and test clearer question wording in a separately planned comparison |

The treatment produced more work for sales and fewer observed qualified leads. A higher form rate alone would have hidden this. The small number of qualified outcomes also means the size of the difference remains uncertain.

## Process and checklist

1. Verify successful submission tracking and stable assignment.
2. Define quality independently of which page was seen.
3. Keep sales response expectations comparable.
4. Wait for qualification and review missing outcomes.
5. Report raw counts, business trade-offs and uncertainty.

- [ ] One meaningful change is identifiable.
- [ ] Visitors are not repeatedly switched between variants.
- [ ] Qualified outcomes use the same definition.
- [ ] Sales effort and technical failures are visible.
