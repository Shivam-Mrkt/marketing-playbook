# SEO experiments

SEO changes often lack clean random assignment. Document the comparison and competing explanations so a useful observation does not become an unsupported causal claim.

## Illustrative example: B2B SaaS

All figures below are fictional teaching data for RelayDesk.

| Stage | Record |
| --- | --- |
| Problem | A routing-method comparison gets relevant impressions but few evaluation visits |
| Hypothesis | A clearer comparison and worked scenarios will make the page more useful for evaluation intent |
| Change | Add a decision table and two implementation scenarios; keep URL and commercial offer unchanged |
| Metric | Relevant organic clicks and qualified enquiries; indexing and query mix are guardrails |
| Test | Six weeks before versus six weeks after confirmed recrawl; compare with unchanged related pages and record major site changes |
| Result | Updated page: 400 to 520 organic clicks, +30%. Comparison group: 1,000 to 1,150, +15%. Qualified enquiries: four to six on the updated page |
| Learning | The page improved more than the comparison group, but seasonality, ranking changes and non-equivalent pages remain plausible explanations. Two additional enquiries are weak commercial evidence |
| Next action | Keep the useful content, monitor another declared period and avoid claiming a 30% causal lift |

## Process

1. Choose an existing page with a clear intent and measurable baseline.
2. Record the exact change, publication date and subsequent discovery/recrawl evidence.
3. Select comparison pages before seeing the result.
4. Record external events and other site changes.
5. Analyse query relevance and downstream outcomes, not total traffic alone.

## AI-search extension

For an information-accuracy test, keep a fixed set of buyer questions and log system, date, locale and cited sources. A changed answer is an observation; model updates and retrieval variability can also explain it. Do not promise that a content edit will cause mentions.

## Practical checklist

- [ ] Comparison period and page group chosen in advance.
- [ ] Recrawl and indexing considered.
- [ ] External explanations documented.
- [ ] Small conversion counts are not overstated.
