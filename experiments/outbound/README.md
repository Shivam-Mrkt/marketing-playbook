# Outbound experiments

Test relevance and the requested next step before increasing volume. Assign at account level where multiple contacts could influence each other, and keep suppression rules identical across variants.

## Illustrative example: B2B SaaS

These are fictional teaching figures for RelayDesk, not Shivam's results.

| Stage | Record |
| --- | --- |
| Problem | Suitable accounts rarely accept a meeting from the first email |
| Hypothesis | Offering a territory-rules checklist will create more qualified conversations than asking directly for a demo |
| Change | Resource CTA versus demo CTA; same verified context and core message |
| Metric | Qualified conversations per delivered account; opt-outs and negative replies are guardrails |
| Test | Randomly assign 200 comparable accounts, one initial contact per account, 100 per arm; run for three weeks plus one week for response handling |
| Result | Resource CTA: 12 positive replies, six qualified conversations. Demo CTA: eight positive replies, five qualified conversations. All 100 accounts in each arm had delivery in this illustrative dataset |
| Learning | The resource offer generated more positive replies but only one more qualified conversation. This is insufficient evidence to declare a commercially meaningful winner |
| Next action | Review reply substance and follow-up effort; design a larger comparison only if the potential gain warrants it |

## Step-by-step process

1. Balance account fit and relevant signals before random assignment.
2. Change one message element and keep follow-up handling comparable.
3. Define “positive” and “qualified” before reviewing replies.
4. Stop scheduled touches on replies or opt-outs.
5. Report delivery failures separately and inspect whether they differ by arm.

## Practical checklist

- [ ] One account cannot enter both arms.
- [ ] Contact sources and sending eligibility reviewed.
- [ ] Reply classification is consistent.
- [ ] Qualified conversations, not opens, guide the decision.
- [ ] Small differences are reported honestly.
