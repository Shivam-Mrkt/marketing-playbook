# Paid acquisition experiments

These completed teaching records use invented figures. They show decision logic, not Shivam's results or statistically proven improvements.

## Illustrative example: Google Ads — B2B SaaS

| Stage | Record |
| --- | --- |
| Problem | Fictional RelayDesk sends territory-routing searches to a general product page |
| Hypothesis | A territory-specific page will improve qualified leads per eligible visitor |
| Change | Replace the general explanation with a territory workflow; keep offer and form consistent |
| Metric | Qualified leads per eligible visitor; form-error rate and qualified volume are guardrails |
| Test | Four-week directional pilot with a stable random split; same eligible Search traffic, then 14 days for qualification |
| Result | Control: 1,000 visitors, 50 leads, 20 qualified. Treatment: 1,000 visitors, 60 leads, 27 qualified. Qualified conversion: 2.0% versus 2.7% |
| Learning | A 0.7 percentage-point observed difference is promising, but these limited outcomes do not establish a reliable lift |
| Next action | Retain a controlled comparison and define a new sample plan before broader rollout; inspect sales feedback first |

The follow-on plan must be declared before collecting its data. Do not silently extend the original pilot until it appears conclusive.

## Illustrative example: Meta Ads — D2C ecommerce

| Stage | Record |
| --- | --- |
| Problem | Fictional AlderCarry's lifestyle image may not explain bag organisation |
| Hypothesis | A compartment demonstration will lower new-customer acquisition cost |
| Change | Demonstration creative versus lifestyle creative; same offer and destination |
| Metric | Media-only new-customer CAC; contribution and refund rate are guardrails |
| Test | Three-week directional platform split test, with a 30-day returns review; $1,500 per arm |
| Result | Control: 30 new customers, $50 media CAC. Treatment: 36, about $41.67 media CAC. At $90 per order, attributed revenue is $2,700 and $3,240 before any returns |
| Learning | Demonstration has better observed acquisition efficiency, but low purchase counts and returns uncertainty limit the decision |
| Next action | Check contribution and completed returns data; plan a larger test of the concept if economics still support it |

## Practical checklist

- [ ] Platform split or assignment method is documented.
- [ ] Creative test does not also change the offer.
- [ ] Lead or customer quality is observed after conversion.
- [ ] Spend and outcome delays are comparable.
- [ ] Absolute counts accompany percentage changes.
