# Marketing experiments

Experiments make an uncertain decision more explicit. A useful test can support a change, reject a hypothesis or show that the evidence is still insufficient.

## Start here

Read the [experiment framework](experiment-framework.md), then adapt the [experiment template](../templates/experiment-template.md).

Problem → Hypothesis → Change → Metric → Test → Result → Learning → Next action

Every numerical result in this folder is an **Illustrative example** using fictional businesses. None represents Shivam's achieved results. Completed examples demonstrate how to write a result and decide what it can support; they are not evidence that the proposed tactics will work elsewhere.

## Review rhythm

Before launch, agree the hypothesis, primary metric, assignment unit, evaluation window and stopping rules. During the test, check delivery and guardrails without repeatedly choosing a winner. At review, inspect data quality and uncertainty before deciding to roll out, repeat, revise or stop.

## Checklist

- [ ] Test answers a real pending decision.
- [ ] One material change can be understood.
- [ ] Primary metric and guardrails are declared in advance.
- [ ] Negative and inconclusive results are documented.
- [ ] Next action follows the evidence rather than the preferred story.
