# Conversion optimisation

Conversion work begins with diagnosis. A weak result can come from unsuitable traffic, an unclear page, poor-fit enquiries or a broken sales handoff. Each requires a different response.

## Start with the symptom

| Symptom | First investigation | Guide |
| --- | --- | --- |
| Visitors do not understand the offer | Promise, proof and friction | [Landing-page audit](landing-page-audit.md) |
| Suitable traffic rarely takes the next step | Form and offer performance | [Conversion rate](conversion-rate.md) |
| A later stage is weak | Stage definitions, delays and handoffs | [Funnel analysis](funnel-analysis.md) |
| Many enquiries are unsuitable | Source, offer and qualification | [Lead quality](lead-quality.md) |

## Process

1. Verify measurement before interpreting a drop.
2. Segment by source, intent, device and acquisition cohort.
3. Find the first meaningful stage where performance changes.
4. Inspect evidence from users and owners at that stage.
5. Test one meaningful change and monitor downstream quality.

**Illustrative example: B2B SaaS.** RelayDesk's form completion rises after a redesign, but accepted leads fall. The team checks whether removed qualification context attracted unsuitable enquiries before celebrating the higher conversion rate.

## Checklist

- [ ] Conversion event and denominator are named.
- [ ] Cohorts have enough time to progress.
- [ ] Tracking errors are ruled out.
- [ ] Test has a quality guardrail.
