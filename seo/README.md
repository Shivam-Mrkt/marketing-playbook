# SEO

SEO starts with what a buyer needs to understand. Ranking for a loosely related topic has little value if the page cannot help that audience take a useful next step.

## Process

1. Gather customer questions and search evidence.
2. Map intent to existing pages before commissioning new ones.
3. Remove access problems that prevent useful pages from being discovered.
4. Publish first-party expertise with a clear next step.
5. Review query relevance, qualified conversions and assisted journeys.

**Illustrative example: B2B SaaS.** RelayDesk separates a “what is lead routing?” guide from a “lead routing software” product page. The guide explains the process; the product page helps someone evaluate the tool. They link where that transition helps the reader.

## Review checklist

- [ ] Each priority page has a distinct audience need.
- [ ] Existing content was considered before creating another URL.
- [ ] A subject expert reviewed claims and examples.
- [ ] Organic outcomes distinguish brand and non-brand demand.
