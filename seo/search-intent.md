# Search intent

## Why it matters

A useful page answers the task behind the query. A product pitch can disappoint someone learning a concept, while a long definition can frustrate someone comparing suppliers.

## Framework

| Intent | Typical question | Page job | Suitable next step |
| --- | --- | --- | --- |
| Informational | How does this work? | Explain with a worked example | Related guide or worksheet |
| Commercial investigation | Which approach suits us? | Compare criteria and trade-offs | Evaluation checklist |
| Transactional | Where can I get this? | Explain offer, fit and terms | Demo, trial or purchase |
| Navigational | Where is this brand's page? | Get the person to the right destination | Relevant product or support action |

These categories are working labels. A results page can contain mixed intent, and a person can move between tasks.

## Step-by-step process

1. Read the full query and its context; do not classify from one word.
2. Inspect the current results: page types, formats, features and common questions.
3. Write a one-sentence task: “The reader needs to choose a routing method for a small team.”
4. Choose the page format and first useful answer.
5. Address adjacent questions only when they help that task.
6. Match the CTA to readiness and inspect actual query performance after publishing.

## Illustrative example: B2B SaaS

“Round robin vs territory routing” calls for a comparison, not a generic software homepage. RelayDesk's fictional guide compares fairness, account ownership and maintenance effort, then gives scenarios where each method fits. The CTA offers sample assignment rules before asking for a demo.

## Metrics and mistakes

Monitor relevant query coverage, useful next-step clicks and qualified conversions. Short time on page can mean a quick answer, not failure. Do not copy the current top result's outline blindly or stuff every intent into one page.

## Practical checklist

- [ ] Reader's task is stated before writing.
- [ ] Format fits the observed results and audience need.
- [ ] Main answer appears early.
- [ ] CTA is a plausible next step.

**Experiment idea:** move a comparison table above the product explanation. Inspect evaluation CTA use and qualified enquiries, while noting traffic-mix changes.
