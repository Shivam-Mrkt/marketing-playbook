# Outbound marketing

Outbound should make a reasonable connection between a person's professional context and a useful offer. Relevance is the reason to contact someone; a large list is not.

## Before sending

1. Define a fit segment and the problem hypothesis.
2. Verify the professional context and contact source.
3. Check the applicable sending requirements and channel policies with the business owner; this playbook is an operating framework, not jurisdiction-specific legal advice.
4. Use truthful sender identity, a clear purpose and an easy way to decline.
5. Set suppression and ownership rules before any sequence begins.

**Illustrative example: B2B SaaS.** RelayDesk approaches NorthstarOps about territory ownership after a fictional expansion announcement. It offers a relevant checklist and asks a question. It does not claim to know internal problems or imply an existing relationship.

## Review checklist

- [ ] The message would still be useful without a meeting booking.
- [ ] Personalisation is accurate and professionally relevant.
- [ ] Replies are read by an accountable person.
- [ ] Opt-outs stop future promotional touches across connected workflows.

Measure positive replies, qualified meetings held and opportunities per contacted account. Opens are too noisy to be the main optimisation target. Start from [account research](../abm/account-research.md). [Back to the playbook](../README.md).
