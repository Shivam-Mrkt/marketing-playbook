# Content brief template

Use before drafting a new page or a substantial refresh. The brief should explain the reader's task and the original contribution, not just provide a keyword list.

## Illustrative example: B2B SaaS

Proposed page for fictional RelayDesk.

| Field | Completed example |
| --- | --- |
| Topic | Round robin versus territory-based lead routing |
| Primary intent | Compare assignment methods and choose a practical approach |
| Audience | Revenue operations managers reviewing lead ownership |
| Problem | Different methods trade off fairness, account context and maintenance |
| Angle | Choose based on operating rules and exceptions, with two worked scenarios |
| Outline | Brief answer; comparison table; when each fits; overlap exceptions; implementation checklist; next step |
| Internal links | Routing overview for context; routing checklist for implementation; product page for evaluation |
| CTA | Use the assignment-rules worksheet; optional workflow demo |
| SERP considerations | Inspect live results in the target market before drafting; confirm comparison intent and avoid duplicating an existing page |
| First-party contribution | Subject expert explains a sample conflict between named-account and territory rules |
| Evidence | Verify product claims; scenario numbers remain explicitly fictional |
| Owner | Content marketer drafts; operations specialist reviews; SEO owner checks intent and page overlap |
| Measurement | Relevant query clicks, worksheet use and qualified evaluation enquiries |
| Refresh trigger | Product rules change, recurring buyer questions shift or search intent no longer fits |

## Acceptance checklist

- [ ] Reader gets a useful answer near the start.
- [ ] Comparison includes limits and trade-offs.
- [ ] Internal links serve a reader need.
- [ ] Claims and examples have been reviewed.
- [ ] Page adds value beyond summaries of existing results.
