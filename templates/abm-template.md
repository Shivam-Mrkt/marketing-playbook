# ABM account-plan template

Use one plan per priority account. The account owner should be able to identify the next useful action without reading a long research dossier.

## Illustrative example: B2B SaaS

RelayDesk and NorthstarOps are fictional; the plan describes a proposed campaign, not an actual relationship.

| Field | Completed example |
| --- | --- |
| Account | NorthstarOps, 180-person software company |
| ICP fit | Industry and size fit; supported CRM must still be confirmed |
| Tier | Tier 1 research priority because expansion may affect ownership rules |
| Buying signals | Fictional public announcement of a European sales team; six weeks old in the scenario |
| Contacts | Revenue operations manager first; sales director and IT reviewer if evaluation proceeds |
| Pain points | Territory overlap is a hypothesis; no internal loss or urgency confirmed |
| Personalisation | Ask how regional expansion affects lead ownership; offer a rules checklist |
| Channels | Relevant email, appropriate LinkedIn context; paid support only if audience coverage is viable |
| Sequence | Day 1 context; day 5 practical example; day 10 professional-network context; day 16 close loop |
| Owner | Account executive coordinates; ABM marketer researches and prepares material |
| Status | Proposed research sprint; no outreach sent and no opportunity created |
| Qualification gate | Confirm problem, fit and agreed evaluation next step |
| Measurement | Meaningful account engagement, qualified meeting held, opportunity progression |
| Next action | Verify CRM and current role, then approve factual accuracy internally before execution |

## Review checklist

- [ ] Existing opportunities and relationships checked.
- [ ] Facts, hypotheses and unknowns are distinct.
- [ ] One owner coordinates channels.
- [ ] Replies and opt-outs stop scheduled messages.
- [ ] Pipeline is created only after the agreed evidence gate.
